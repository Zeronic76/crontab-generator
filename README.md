# Cronjob Generator

Ein leichtgewichtiger, intuitiver und webbasierter Cronjob-Generator, mit dem sich Crontab-Zeitpläne schnell und fehlerfrei erstellen lassen. 

Das Tool ist ideal für Systemadministratoren und Entwickler, die Cron-Ausdrücke visuell zusammenklicken möchten, anstatt die Syntax jedes Mal manuell nachzuschlagen.

👉 **Live-Demo:** [block-topia.de/public/crongen/index.php](https://block-topia.de/public/crongen/index.php)

---

## 🚀 Features

- **Intuitive Benutzeroberfläche:** Generiere komplexe Cron-Ausdrücke mit wenigen Klicks.
- **Volle Flexibilität:** Unterstützung für Minuten, Stunden, Tage, Monate und Wochentage.
- **Direkte Vorschau:** Der fertige Crontab-Befehl wird sofort einsatzbereit generiert.
- **Leichtgewichtig & Schnell:** Pures PHP/Web-Skript ohne überladene Frameworks.

## 🛠️ Installation & Nutzung

Da das Projekt self-contained ist, kannst du es extrem einfach auf deinem eigenen Webserver (z. B. Apache/Nginx mit PHP) betreiben.
